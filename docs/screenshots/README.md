# Screenshots

The main README shows these four files. Take them on a running instance with
live API keys, ideally after it has run for most of a day so the analytics
charts are filled in. A window about 1600 px wide gives clean images.

| File | What to show |
|---|---|
| `overview.png` | Whole of Australia, all layers on, Analytics closed |
| `sydney.png` | Zoomed to Sydney (around zoom 10–11): cameras, ships in the harbour, aircraft |
| `popups.png` | A camera popup with its image (or a fire popup) |
| `analytics.png` | The Analytics panel open, showing the hourly flights chart |

PNG, under about 1 MB each. On macOS, `Cmd + Shift + 4` then `Space` captures one window.
